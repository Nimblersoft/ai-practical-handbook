# AI agent

[English index](../../en.md) · [Español](es.md)

**AI agent.** A system that uses AI to work toward a goal, deciding which steps to take and using the tools it has permission to access. Unlike a chat tool that only suggests a plan, an agent can carry out parts of it.

**Example:** A scheduling agent checks team calendars and proposes three times. If the tool supports it, set it to ask for your approval before sending an invitation.

**See also:** [AI assistant](../ai-assistant/en.md), [human oversight](../human-oversight/en.md).
