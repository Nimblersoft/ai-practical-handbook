# Automation

[English index](../../en.md) · [Español](es.md)

**Automation.** Setting up a task to happen without someone doing it manually each time. It can follow a fixed rule and does not necessarily use AI.

**Example:** Sending a rent reminder on the first of every month is automation. Using AI to draft a personalized reminder is a separate step.

**See also:** [Artificial intelligence](../artificial-intelligence/en.md), [AI agent](../ai-agent/en.md).
