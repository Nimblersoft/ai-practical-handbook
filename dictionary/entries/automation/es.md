# Automatización

[Índice en español](../../es.md) · [English](en.md)

**Automatización.** Configurar una tarea para que se realice sin que alguien tenga que hacerla manualmente cada vez. Puede seguir una regla fija y no necesita usar IA.

**Ejemplo:** Enviar un recordatorio de alquiler el primer día de cada mes es automatización. Usar IA para redactar un recordatorio personalizado es un paso aparte.

**Véase también:** [Inteligencia artificial](../artificial-intelligence/es.md), [agente de IA](../ai-agent/es.md).
