# Evaluation

[English index](../../en.md) · [Español](es.md)

**Evaluation.** Checking how well an AI system does a particular job using examples and criteria chosen in advance. A strong result on one task does not guarantee a strong result on another.

**Example:** Before using AI to summarize meetings, test it on a few sample meetings. Check whether it gets decisions right, leaves out key details, or attributes comments to the wrong person.

**See also:** [Bias](../bias/en.md), [human oversight](../human-oversight/en.md).
