# Generative AI (GenAI)

[English index](../../en.md) · [Español](es.md)

**Generative AI (GenAI).** AI that produces content such as text, images, audio, or video using patterns it learned from examples. Its output can look polished and still contain errors.

**Example:** An AI tool can write three versions of a birthday invitation. If one adds an address you never provided, check and correct it before sharing.
