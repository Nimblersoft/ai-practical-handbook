# Machine learning (ML)

[English index](../../en.md) · [Español](es.md)

**Machine learning (ML).** A way to build systems by using data to learn patterns instead of writing a separate rule for every situation. The system can then apply those patterns to new examples.

**Example:** A spam filter learns patterns from email marked as spam or not spam. It can then make a prediction about a message it has never seen.
