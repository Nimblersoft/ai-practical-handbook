# Aprendizaje automático (machine learning, ML)

[Índice en español](../../es.md) · [English](en.md)

**Aprendizaje automático (machine learning, ML).** Una forma de crear sistemas que aprenden patrones a partir de datos, en vez de escribir una regla para cada situación. Luego el sistema puede aplicar esos patrones a ejemplos nuevos.

**Ejemplo:** Un filtro aprende de correos marcados como basura o legítimos. Después puede predecir si un mensaje que nunca había visto es correo basura.
