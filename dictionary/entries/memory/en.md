# Memory

[English index](../../en.md) · [Español](es.md)

**Memory.** A feature that lets an AI tool save or retrieve selected information for later conversations. This is different from using earlier messages in the current chat or changing the model through training. What is remembered depends on the tool and its settings.

**Example:** An assistant may remember that you prefer short answers when you start a new chat. Check its settings to see what you can view or remove. Turning off memory does not necessarily stop the service from saving chat history.

**See also:** [Context window](../context-window/en.md), [personal data](../personal-data/en.md).
