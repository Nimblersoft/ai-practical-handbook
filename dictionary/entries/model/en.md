# Model

[English index](../../en.md) · [Español](es.md)

**Model.** The part of an AI tool that applies learned patterns to make predictions or produce results. The app you open can add its own features, such as web search or a way to upload a file.

**Example:** Two apps can use the same writing model, but only one may let it work with a document you upload.

**See also:** [Large language model](../large-language-model/en.md), [training data](../training-data/en.md).
