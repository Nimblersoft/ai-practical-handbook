# Modelo

[Índice en español](../../es.md) · [English](en.md)

**Modelo.** La parte de una herramienta de IA que aplica patrones aprendidos para hacer predicciones o producir resultados. La aplicación que abres puede añadir sus propias funciones, como buscar en internet o subir un archivo.

**Ejemplo:** Dos aplicaciones pueden usar el mismo modelo de escritura, pero quizá solo una le permita trabajar con un documento que subas.

**Véase también:** [Modelo de lenguaje de gran tamaño](../large-language-model/es.md), [datos de entrenamiento](../training-data/es.md).
