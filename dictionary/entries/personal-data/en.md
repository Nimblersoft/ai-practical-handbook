# Personal data

[English index](../../en.md) · [Español](es.md)

**Personal data.** Information about someone who can be identified directly or by combining details. A name or ID number can identify someone, but so can a combination such as a job title and a small workplace.

**Example:** Before pasting a customer email into an AI tool, check which tools and data your organization allows. If the task does not need real details, use a fictional example instead.

**See also:** [Memory](../memory/en.md), [training data](../training-data/en.md).
