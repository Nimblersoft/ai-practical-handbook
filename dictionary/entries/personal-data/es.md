# Datos personales

[Índice en español](../../es.md) · [English](en.md)

**Datos personales.** Información sobre alguien a quien se puede identificar, de forma directa o al combinar varios detalles. Un nombre o número de identificación puede bastar, pero también puede bastar la combinación de un cargo y un lugar de trabajo pequeño.

**Ejemplo:** Antes de copiar un correo de un cliente en una herramienta de IA, comprueba qué herramientas y datos permite tu organización. Si la tarea no necesita datos reales, usa un ejemplo ficticio.

**Véase también:** [Memoria](../memory/es.md), [datos de entrenamiento](../training-data/es.md).
