# Sistema de recomendación

[Índice en español](../../es.md) · [English](en.md)

**Sistema de recomendación.** Un sistema que selecciona u ordena lo que te muestra, como videos, productos o canciones. Puede usar tu actividad, las opciones más populares o las similitudes entre elementos.

**Ejemplo:** Después de que escuchas varias canciones de un artista, la aplicación te sugiere otros artistas. Las sugerencias pueden reflejar lo que la aplicación busca promover, no solo tus gustos.

**Véase también:** [Inteligencia artificial](../artificial-intelligence/es.md), [sesgo](../bias/es.md).
