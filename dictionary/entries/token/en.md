# Token

[English index](../../en.md) · [Español](es.md)

**Token.** A unit a language model uses to handle text. It might be a whole word, part of a word, or a punctuation mark. The count can vary by model and language, so tokens are not the same as words.

**Example:** If a tool has a limit measured in tokens, a document’s word count alone won’t tell you whether the whole document fits.

**See also:** [Large language model](../large-language-model/en.md), [context window](../context-window/en.md).
