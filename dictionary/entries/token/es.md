# Token

[Índice en español](../../es.md) · [English](en.md)

**Token.** Una unidad que usa un modelo de lenguaje para procesar texto. Puede ser una palabra entera, parte de una palabra o un signo de puntuación. La cantidad puede variar según el modelo y el idioma: contar tokens no es lo mismo que contar palabras.

**Ejemplo:** Si una herramienta tiene un límite medido en tokens, contar las palabras de un documento no basta para saber si cabe completo.
