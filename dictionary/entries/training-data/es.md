# Datos de entrenamiento

[Índice en español](../../es.md) · [English](en.md)

**Datos de entrenamiento.** La información que se usa al desarrollar un modelo para que aprenda patrones. No es lo mismo que la información que le das para una respuesta. Que un proveedor use después lo que envías para entrenar un modelo depende de sus políticas y de tu configuración.

**Ejemplo:** Un modelo para reconocer señales de tránsito puede aprender con miles de fotos etiquetadas. Una foto que envíes más tarde sirve como entrada para la herramienta, pero no pasa automáticamente a formar parte de sus datos de entrenamiento.

**Véase también:** [Aprendizaje automático](../machine-learning/es.md), [datos personales](../personal-data/es.md).
